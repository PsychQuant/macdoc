Implements design decision D3 (paraId stamped at authoring chokepoints, generated by an injectable per-document generator) and the spec requirement "Authoring chokepoints stamp w14:paraId".

- [x] [P] 1.1 (design D3 — paraId stamped at authoring chokepoints, generated by an injectable per-document generator) Add `ParaIdGenerator` in packages/ooxml-swift/Sources/OOXMLSwift/Models/ParaIdGenerator.swift. Verify: new unit tests in packages/ooxml-swift/Tests/OOXMLSwiftTests/ParaIdGeneratorTests.swift assert format regex `[0-9A-F]{8}`, range bounds (0x00000000 and values >= 0x80000000 never emitted), collision skip against a preloaded set, and a seeded generator yields a reproducible sequence; `swift test --filter ParaIdGeneratorTests` passes.
