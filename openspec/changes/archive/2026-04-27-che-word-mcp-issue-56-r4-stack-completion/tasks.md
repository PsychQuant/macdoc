## 0. Requirement / Decision coverage map

This R5 stack covers the following requirements and design decisions. Each task section below cites the requirement or decision it implements.

**Requirements implemented:**

- "Revision accept/reject SHALL find mixed-content wrappers across all document parts" → §2 (P0 #1)
- "DocxReader SHALL propagate typed Revisions from block-level SDT children into document.revisions.revisions" → §5 (P0 #4)
- "DocxReader SHALL capture w:tbl direct children of header, footer, footnote, and endnote roots" → §7 (P0 #6)
- "DocxReader SHALL assign source paragraph child positions starting at 1" → §3 (P0 #2)
- "ooxml-swift SHALL provide a single shared XML attribute escape helper" → §1.1 + §4 (P0 #3 part A)
- "Caller-provided String values for w:val, w:color, w:name, w:fill, w:author, w:moveId attributes SHALL be routed through escapeXMLAttribute" → §4 (P0 #3 part B)
- "Issue56R4StackTests SHALL include an allow-list audit table for emit sites NOT routed through escapeXMLAttribute" → §4.13 + §1.4
- "Issue #56 R5 stack regression tests SHALL exercise full save then re-read roundtrip" → §1.2 (helper) + §2-§8 (every test uses the helper)
- "Issue56R3StackTests SHALL gain RoundtripVariants test group exercising the same fixtures with save-reread" → §9 (R3 stack roundtrip variants)

**Design Decisions covered:**

- Decision 1: unified walker abstraction `walkAllParagraphs` vs ad-hoc walkers → §1.3 (`DocumentWalker.swift`) + §2.4 (caller refactor) + §7.7 (container recursion) + §8.3 (cross-part hyperlink ops)
- Decision 2: hyperlink mutation detection — deep equality vs explicit dirty flag → §8.1 (deep equality on `[Run]`)
- Decision 3: SDT position sentinel — reader-side `position >= 1` vs caller-side check → §3.3-§3.6 (reader assigns from 1, sorted-emit drops `> 0` filter)
- Decision 4: XML attribute escape — shared module + allow-list audit → §1.1 (helper module) + §4 (sweep) + §4.13 (allow-list comment) + §1.4 (initial empty allow-list)
- Decision 5: container parser `<w:tbl>` capture — extend `paragraphs` vs add `bodyChildren` → §7.3-§7.7 (`parseContainerBody`, `bodyChildren` field, computed `paragraphs` view, walker recursion)
- Decision 6: test pattern — save→reread roundtrip mandate → §1.2 (`RoundtripHelper`) + §2.1-§8.3 (every R5 test uses it) + §9 (R3 roundtrip variants)
- Decision 7: release artifact handling — skip v0.19.4 vs back-out → §10.1 (CHANGELOG rename `[0.19.4]` → `[0.19.5]` + Skipped versions subsection) + §10.5 (tag v0.19.5) + §10.7 (v3.13.5)
